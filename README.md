# Analyse économique du Maroc

## Présentation du projet

Ce projet a été réalisé dans le cadre d’un travail académique en économie.

L’objectif est d’analyser les principaux facteurs qui peuvent freiner la croissance économique au Maroc à partir de données statistiques et d’une analyse graphique.

## Problématique

**Qu’est-ce qui freine la croissance économique au Maroc ?**

## Données utilisées

Le projet utilise notamment des données relatives à :

* la croissance du PIB ;
* le taux de chômage ;
* l’évolution de la situation économique du Maroc.

Les données sont disponibles dans le dossier **`data`**.

## Analyse

Le programme Python utilisé pour traiter les données et produire le graphique se trouve dans le dossier **`src`**.

Le graphique obtenu est disponible dans le dossier **`figures`**.

Le rapport présentant les résultats et leur interprétation se trouve dans le dossier **`rapport`**.
